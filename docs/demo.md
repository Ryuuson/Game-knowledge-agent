# 使用示例

在项目根目录运行 `scripts/run.ps1`，浏览器打开 `http://127.0.0.1:8501`。

## 查找游戏设计资料

默认模式为“离线检索演示”。选择检索策略、设置片段数量，再输入问题：

> 玩家在游戏后期金币越来越多，经济系统应该怎么设计回收机制？

展开“查看检索依据”，查看资料标题、章节、来源链接和原文片段。BM25 返回关键词候选；BGE 和混合检索需要本地模型缓存与索引。语义服务不可用时，界面会标明降级。

离线模式只返回资料，不生成模型回答。明确属于其他行业的问题，例如“医院预约挂号流程应该怎么设计？”，会提示游戏资料不适用。

## 连续讨论设计问题

按 [README](../README.md#聊天配置) 配置聊天服务后，切换到“对话助手”，新建会话并提问：

> 游戏角色技能的伤害与冷却如何搭配，避免唯一解？

可以继续追问“如果面向新手呢？”。回答中的来源编号对应检索片段，展开依据可对照原文。

会话历史保存在本机。侧栏支持切换、恢复和删除会话；“导出对话与来源”将回答及资料来源保存为 Markdown。

聊天与摘要会调用配置的远程模型。可选联网搜索和 OCR 使用各自接口。
