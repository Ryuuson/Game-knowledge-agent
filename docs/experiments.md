# 检索实验

比较 BGE 语义检索、BM25 关键词检索与 RRF 混合检索。实验环境为 Windows、CPython 3.10.9、CPU；记录日期为 2026-10-11。完整结果见 [实验数据](../evals/reference_results/2026-10-11.json)。

## 数据与方法

语料包含四个来源、5,285 个知识块；BGE 模型为 `BAAI/bge-small-zh-v1.5`，向量为 512 维。

回归集共 30 条 AI 辅助构造案例：20 条游戏正例，每个来源各五条，共标注 27 个支持块；10 条非游戏问题用于计算拒答。案例构造时可见语料，未经独立人工相关性审核，标签也未穷举所有等价证据。这些结果用于实现比较与回归检查，不代表通用回答准确率。

Top-k 为 5。混合检索使用 RRF 合并两路候选，再按原始 BGE 余弦分数筛选；默认阈值为 0.62，高相关阈值为 0.67。阈值未用本回归集调参。

排名路径关闭语义阈值，保留领域规则；阈值路径单独调用生产检索服务，并允许深层候选补位。BM25 没有语义阈值。BGE 或混合检索发生降级时，该模式实验无效。

Recall@5 是每条正例命中的标注块比例再宏平均；MRR 是首个标注块名次倒数的均值；nDCG 使用二元相关性；Hit@5 是至少命中一个标注块的正例比例。排名指标以 20 条正例为分母，非游戏拒答单独以 10 条负例为分母。

## 结果

| 排名路径 | Recall@5 | MRR | nDCG@5 | Hit@5 |
| --- | ---: | ---: | ---: | ---: |
| BGE | 57.5% | 0.4267 | 0.4583 | 60.0% |
| BM25 | 77.5% | 0.6917 | 0.7034 | 80.0% |
| BGE + BM25 / RRF | 70.0% | 0.6417 | 0.6416 | 75.0% |

| 阈值路径 | Recall@5 | MRR | nDCG@5 | Hit@5 | 非游戏拒答 | 游戏误拒 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| BGE | 42.5% | 0.3417 | 0.3574 | 45.0% | 10/10 | 5/20 |
| BM25 | 77.5% | 0.6917 | 0.7034 | 80.0% | 8/10 | 0/20 |
| BGE + BM25 / RRF | 50.0% | 0.4667 | 0.4591 | 55.0% | 10/10 | 5/20 |

BM25 在该集合中召回更多标注块，但对两条非游戏问题仍返回候选。BGE 阈值减少了非游戏候选，也误拒五条正常游戏问题。混合策略提高了部分召回，代价是更多检索开销。结果反映当前语料和标注的取舍，尚不足以确定普遍最优策略。

## 延迟与内存

| 策略 | 正例查询 p50 | p95 | 首次预热 | 结束时进程 RSS |
| --- | ---: | ---: | ---: | ---: |
| BGE | 22.20 ms | 34.21 ms | 51,918.90 ms | 530.2 MiB |
| BM25 | 11.93 ms | 14.82 ms | 1,159.77 ms | 599.4 MiB |
| BGE + BM25 / RRF | 41.30 ms | 52.03 ms | 1,011.56 ms | 610.3 MiB |

每种模式预热一次，然后按固定顺序执行案例；延迟统计为 20 条正例的排名查询，包含编码和检索，不含 UI、网络与生成。每例执行一次，没有重复抽样或置信区间。

三种模式在同一进程执行并共享模型缓存。BGE 首次预热包含模型加载，混合预热已复用模型；RSS 包含此前模式保留的模型和索引，不能视为单模式独占内存或独立冷启动指标。

## 典型失败案例

| 案例 | 观察 |
| --- | --- |
| `numeric-aggro-taunt` | BGE 找到同主题其他块，但未命中选定编号；需要进一步检查等价证据标注。 |
| `mechanics-gacha-pity` | 三种策略均未命中标注块；BGE 与混合在阈值后无证据。 |
| `reject-payroll-unseen` / `reject-admissions-unseen` | BM25 返回候选，领域规则未识别相应语境。 |

## 复现

准备 JSONL、匹配的 SQLite 索引与本地模型缓存后运行：

```powershell
.\.venv\Scripts\python.exe -X utf8 scripts/evaluate_retrieval.py --backend all --top-k 5 --output .runtime/retrieval_evaluation.json
```

结果保存输入和代码指纹、配置、环境、逐案例命中及耗时。评估集定义、参数和指标详情见 [评估说明](../evals/README.md)。
